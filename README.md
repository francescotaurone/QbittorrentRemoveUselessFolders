# Qbittorrent Remove Useless Folders

Sometimes you want to extract .rar files directly in bittorrent, but then these files don't get deleted once you remove torrents and files using qbittorrent.

This simple scripts let's you remove the useless subfolders from the file-tree used by qbittorrent.

Keep in mind that it's a simple snippet made for simple intentions, but it deletes files! Please, review it before using it.

A portion of the codebase has been taken from [this projecy](https://github.com/jerrymakesjelly/autoremove-torrents).
