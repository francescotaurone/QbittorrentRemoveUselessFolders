# Qbittorrent Remove Useless Folders

Sometimes you want to extract .rar files directly in bittorrent, but then these files don't get deleted one you remove torrents and files.

This simple scripts let's you remove the useless subfolders from the filetree used by qbittorrent.

Keep in mind that it's a simple snippet made for simple intentions, but it deletes files! Please, review it before using it.
